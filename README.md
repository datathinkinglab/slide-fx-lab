# Slide FX Lab · HTML 슬라이드 효과 레퍼런스

> 데이터가 말하게 하는 슬라이드의 기술 — **Reveal. Focus. Let the numbers breathe.**

HTML로 강의·발표 슬라이드를 만들 때 바로 가져다 쓸 수 있는 **12가지 시각 효과를 직접 실행해 보고, 핵심 코드를 복사할 수 있는** 인터랙티브 레퍼런스 사이트입니다.
[The Pudding](https://pudding.cool/)의 스토리텔링, [Datawrapper](https://www.datawrapper.de/)의 차트 디자인 원칙, [Flourish](https://flourish.studio/)의 애니메이션·인터랙션 템플릿을 참고해 **외부 라이브러리 없이 순수 HTML·CSS·JavaScript 단일 파일**로 구현했습니다.

🔗 **Live Demo:** https://datathinkinglab.github.io/slide-fx-lab/

## 1. 왜 만들었나

PPT 대신 HTML로 슬라이드를 만들면 **데이터 애니메이션, 단계별 공개, 직접 조작하는 차트**를 넣을 수 있습니다. 문제는 매번 “이 효과를 어떻게 구현했더라?”를 다시 찾는 데 시간이 든다는 점입니다.

Slide FX Lab은 다음 두 가지를 한 화면에서 해결합니다.

- **보기** — 실제 16:9 슬라이드 위에서 효과가 어떻게 움직이는지 확인
- **가져가기** — `N` 키로 열리는 효과 노트에서 “언제 쓰는지 · 팁 · 핵심 코드”를 확인하고 복사

각 효과는 *어떤 메시지를 강화하는가*를 기준으로 골랐습니다. 화려함보다 **청중이 숫자를 이해하는 속도**를 높이는 효과만 담았습니다.

## 2. 주요 기능

| 기능 | 설명 |
|---|---|
| 🎞 **16:9 슬라이드 엔진** | 1600×900 고정 캔버스를 화면 크기에 맞게 자동 스케일. 노트북·대형 모니터·빔프로젝터 어디서나 동일한 레이아웃 |
| ⌨️ **키보드·클릭·스와이프 내비게이션** | ← → / Space / PageUp·Down / 숫자키 1–9 / Home·End, 화면 좌우 클릭, 모바일 스와이프 |
| 🪜 **단계(fragment) 시스템** | 한 슬라이드 안에서 → 키로 단계를 진행하고, 마지막 단계 이후 다음 슬라이드로 이동 |
| 📝 **효과 노트 패널** (`N`) | 효과 이름, 참고 출처, 사용 시점, 디자인 팁, 핵심 코드 + 복사 버튼 |
| 🔁 **다시 재생** (`R`) | 현재 슬라이드의 애니메이션을 처음부터 다시 실행 |
| 🗂 **전체 보기** (`O`) | 12장 전체를 카드 그리드로 보고 원하는 슬라이드로 바로 이동 |
| 🖥 **전체 화면** (`F`) | 발표 모드 |
| 📄 **PDF 저장** (`P`) | 12장 전체를 애니메이션이 끝난 최종 상태로 16:9 한 장씩 PDF에 저장 |
| 🔗 **딥링크** | `#s5`처럼 URL 해시로 특정 슬라이드를 바로 열기 |
| ♿ **모션 감소 대응** | OS의 “동작 줄이기” 설정 시 애니메이션 자동 최소화 |

## 3. 12가지 효과 한눈에 보기

| # | 효과 | 핵심 기법 | 참고 | 이럴 때 쓰세요 |
|:-:|---|---|---|---|
| 01 | **키네틱 타이포 커버** | 단어 단위 마스크 업 + Canvas 웨이브 배경 | 예시 사이트 커버, Pudding | 발표 첫 장, 장 전환 |
| 02 | **빅 넘버 카운트업** | `requestAnimationFrame` 카운터 + 게이지 | Flourish, Pudding | 핵심 KPI 하나를 각인 |
| 03 | **선 그리기 + 지연 주석** | SVG `stroke-dashoffset` + 주석 페이드인 | Datawrapper, Flourish | 추세와 변곡점 설명 |
| 04 | **바 차트 레이스** | 연도 보간 + 실시간 순위 재정렬 + 타임 슬라이더 | Flourish | 순위가 바뀌는 이야기 |
| 05 | **단계별 스토리** | → 키 프래그먼트, 같은 차트 위 강조 전환 | Pudding, Flourish Stories | 한 차트로 여러 메시지 |
| 06 | **와플(단위) 차트** | 100칸 그리드 순차 팝 + 카운트업 | Pudding | 비율을 “사람 수”로 체감 |
| 07 | **비포/애프터 슬라이더** | `clip-path` + 포인터 드래그 | Flourish Photo slider | 도입 전후, 시안 비교 |
| 08 | **포커스 컬러 + 결론형 제목** | 회색 막대 + 강조색 1개, 직접 라벨 | Datawrapper | 여러 항목 중 하나를 말할 때 |
| 09 | **형광펜 하이라이트 인용** | `background-size` 트랜지션 | Pudding | 핵심 문장, 고객 인용 |
| 10 | **순차 타임라인** | `scaleX` 성장 선 + 마일스톤 순차 팝 | Flourish Timeline | 로드맵, 단계형 프레임워크 |
| 11 | **프로그레스 링** | SVG 원 `stroke-dashoffset` + 카운트업 | Flourish Gauge | 단계별 도달률, 목표 달성률 |
| 12 | **원칙 카드 + 공통 등장 효과** | `.rise` 클래스 + `--d` 지연값 | 세 사이트 공통 | 요약·정리 슬라이드 |

> ⚠️ 슬라이드에 사용된 모든 수치는 **효과 시연용 가상 예시 데이터**입니다.

## 4. 조작 방법

| 키 / 동작 | 기능 |
|---|---|
| `→` `Space` `PageDown` · 화면 오른쪽 70% 클릭 | 다음 단계 / 다음 슬라이드 |

## 5. 효과별 상세 설명

### 01 · 키네틱 타이포 커버
제목 텍스트를 JS로 단어마다 `<span class="word"><span style="--i:n">`로 감싸고, 바깥 span에 `overflow:hidden`, 안쪽 span에 `translateY(110%) → 0` 애니메이션을 줍니다. `--i` 값으로 단어마다 0.09초씩 늦게 올라와 리듬이 생깁니다. 배경은 영상 대신 **Canvas 점 격자**에 사인파를 겹쳐 흐르게 만들어 가볍고, 슬라이드를 벗어나면 렌더링을 멈춥니다.

### 02 · 빅 넘버 카운트업
`requestAnimationFrame` + easeOutCubic으로 0에서 목표값까지 올립니다. `font-variant-numeric: tabular-nums`로 숫자 폭을 고정해 카운트 중 글자가 흔들리지 않게 했습니다. `data-count`, `data-dec` 속성만 붙이면 어느 요소든 자동으로 카운트업됩니다.

### 03 · 선 그리기 + 지연 주석
SVG path의 `getTotalLength()`로 길이를 구해 `stroke-dasharray`와 `stroke-dashoffset`에 넣고, offset을 0으로 전환해 선이 그려지게 합니다. **데이터가 먼저, 해석은 나중**이라는 원칙에 따라 주석(“전사 AI 교육 시작”)은 선이 거의 다 그려진 뒤 나타나고, 끝점에는 펄스 효과와 직접 라벨(63%)을 붙였습니다.

### 04 · 바 차트 레이스
연도별 값을 매 프레임 선형 보간해 순위를 다시 계산하고, 막대의 `top`을 CSS transition으로 옮겨 자리바꿈을 부드럽게 보여줍니다. 1위 막대만 강조색으로 바뀌며, 배경의 큰 연도 숫자와 타임 슬라이더로 시간 흐름을 표현합니다.

### 05 · 단계별 스토리 (슬라이드판 스크롤리텔링)
`<section data-steps="3">`처럼 단계 수를 지정하면 → 키가 슬라이드 이동 전에 단계를 먼저 진행합니다. **차트는 고정하고 강조만 바꾸는 것**이 핵심입니다. ① 전체 점 표시 → ② 조건에 맞는 점만 강조색 → ③ 추세선과 결론 라벨 추가.

### 06 · 와플(단위) 차트
10×10 그리드의 각 칸에 `--i`를 주고 `animation-delay: calc(var(--i) * 12ms)`로 순차 등장시킵니다. “37%” 대신 **“100명 중 37명”**으로 바꾸면 청중이 비율을 훨씬 직관적으로 받아들입니다.

### 07 · 비포/애프터 슬라이더
두 패널을 겹친 뒤 위 패널에 `clip-path: inset(0 0 0 var(--x))`를 적용하고, 포인터 위치로 `--x`를 갱신합니다. `setPointerCapture`로 드래그가 영역을 벗어나도 안정적으로 동작하고, 슬라이드 진입 시 손잡이가 살짝 흔들려 조작 가능함을 알려줍니다.

### 08 · 포커스 컬러 + 결론형 제목
Datawrapper 디자인 원칙을 그대로 적용한 가장 범용적인 패턴입니다. 모든 막대는 회색, **말하고 싶은 하나만 강조색**, 범례 없이 막대 끝에 값을 직접 표기, 그리고 제목 자체를 결론으로 씁니다(“부서별 증가율” ❌ → “R&D만 두 배 넘게 늘었다” ✅).

### 09 · 형광펜 하이라이트 인용
`<mark>`에 `linear-gradient` 배경을 깔고 `background-size`를 `0% → 100%`로 전환합니다. 두 번째 하이라이트에 시간차를 주어 **읽는 순서를 유도**합니다.

### 10 · 순차 타임라인
선은 `transform: scaleX(0 → 1)`로 자라고, 각 마일스톤은 선의 진행 속도에 맞춘 지연으로 하나씩 켜집니다. 마지막 단계만 강조색으로 채워 도착점을 강조합니다.

### 11 · 프로그레스 링
원 둘레 `C = 2πr`를 `stroke-dasharray`로 두고, `stroke-dashoffset = C × (1 − 비율)`로 채웁니다. 링마다 200ms 시차, 가운데 숫자는 카운트업과 동기화했습니다.

### 12 · 원칙 카드 + 공통 등장 효과
모든 슬라이드에 쓰인 기본 효과입니다. 요소에 `class="rise"`와 `style="--d:0.3"`(초 단위 지연)만 붙이면 아래에서 떠오르며 나타납니다.

## 6. 임팩트 있는 데이터 슬라이드 7원칙

1. **제목이 결론이다** — 주제가 아니라 답을 제목에 쓴다.
2. **강조색은 하나** — 나머지는 회색. 시선이 갈 곳을 디자이너가 정한다.
3. **범례 대신 직접 라벨** — 선 끝, 막대 옆에 이름과 값을 붙여 시선 이동을 줄인다.
4. **주석은 나중에** — 데이터가 먼저 그려지고, 의미를 설명하는 주석이 뒤따른다.
5. **한 번에 하나씩** — 단계별 공개로 청중이 화자보다 먼저 읽지 않게 한다.
6. **숫자는 사람으로** — 37%보다 “100명 중 37명”.
7. **움직임엔 이유가** — 변화·순위·흐름을 보여줄 때만 애니메이션을 쓴다.

### PDF로 저장하기
1. 우측 상단의 주황색 **PDF 저장** 버튼을 누르거나 `P` 키를 누릅니다.
2. 인쇄 창에서 **대상(Destination)** 을 **PDF로 저장**으로 선택합니다.
3. **배경 그래픽**이 켜져 있는지 확인하고 저장합니다. (용지 크기와 여백은 자동으로 16:9 · 여백 없음으로 맞춰집니다.)

인쇄 직전에 모든 효과를 **최종 상태**로 바꿉니다. 카운터는 최종값으로 표시되고, 선 그래프와 주석, 바 차트 레이스 2026년 순위, 단계별 스토리 3단계, 링 차트가 모두 완성된 모습으로 저장됩니다. 저장이 끝나면 원래 보던 슬라이드로 돌아옵니다. 브라우저의 `Ctrl/⌘ + P`로 인쇄해도 같은 결과가 나옵니다.

> 권장 브라우저: Chrome · Edge (사용자 지정 용지 크기 `@page { size: 1600px 900px }`를 가장 정확하게 지원합니다)

## 7. 기술 구조

```
slide-fx-lab/
├── index.html   # 사이트 전체 (HTML + CSS + JS, 단일 파일 · 약 57KB)
├── README.md
└── .nojekyll    # GitHub Pages에서 Jekyll 처리 생략
```

- **의존성 없음** — 프레임워크·차트 라이브러리 없이 순수 HTML/CSS/JS. 외부 리소스는 Google Fonts뿐입니다.
- **폰트** — Noto Sans KR(본문), Noto Serif KR(인용·강조), IBM Plex Mono(라벨·코드)
- **차트** — 모두 인라인 SVG를 JS로 직접 생성
- **스케일링** — `.stage`(1600×900)를 `translate(-50%,-50%) scale(k)`로 화면에 맞춤

### 코드 구성 (index.html 내부)

| 영역 | 내용 |
|---|---|
| `<style>` `:root` | 색상·폰트·이징 디자인 토큰 |
| `<section class="slide" data-fx="...">` | 슬라이드 12장. `data-fx`가 효과 키, `data-steps`가 단계 수 |
| `<script type="text/plain" id="code-*">` | 효과 노트에 표시되는 코드 스니펫 |
| `META` 객체 | 효과 이름·참고 출처·사용 시점·팁 |
| `ENTER` 객체 | 슬라이드 진입 시 실행할 효과 함수 |
| `go()` / `next()` / `prev()` | 내비게이션과 단계 진행 |
| `finalState()` / `exportPdf()` | PDF 저장 시 모든 효과를 최종 상태로 만들고 인쇄 창 호출 |
| `@media print` | 인쇄 전용 레이아웃(슬라이드 12장을 페이지 단위로 펼침) |

### 디자인 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--paper` | `#f5f1ea` | 밝은 슬라이드 배경 |
| `--night` | `#101217` | 어두운 슬라이드 배경 |
| `--ink` | `#16161a` | 본문 |
| `--mute` | `#b8b2a7` | 비강조 데이터(회색) |

| `--gold` | `#f2b33d` | 보조 강조 |
| `--accent2` | `#1f4e8c` | 보조 색 |

## 8. 내 슬라이드에 적용하는 법

### 방법 A — 코드 조각만 가져가기
1. 사이트에서 원하는 효과 슬라이드로 이동합니다.
2. `N`을 눌러 효과 노트를 열고 **복사**를 누릅니다.
3. 내 HTML 슬라이드에 붙여넣고 `.slide.active` 같은 활성 클래스 이름만 맞춥니다.

### 방법 B — 이 파일을 템플릿으로 쓰기
1. 저장소를 Fork 하거나 `index.html`을 내려받습니다.
2. 새 슬라이드를 추가합니다.

```html
<section class="slide" id="s13" data-fx="myfx">
  <div class="kicker rise">My Effect</div>
  <h2 class="h2 rise" style="--d:.1">결론을 제목으로</h2>
  <div class="big"><span data-count="42">0</span>%</div>
</section>
```

3. `META`에 노트 정보를 추가합니다.

```js
myfx:{title:'내 효과', fx:'사용 기법', refs:['참고처'], when:'사용 시점', tip:'팁'}
```

4. 노트에 표시할 코드를 추가합니다.

```html
<script type="text/plain" id="code-myfx"> ...코드... </script>
```

5. 진입 시 JS 동작이 필요하면 `ENTER`에 함수를 추가합니다. `data-count`만 쓰면 카운트업은 자동입니다.

```js
ENTER.myfx = s => { /* 진입 시 실행 */ };
```

### 단계(fragment) 슬라이드 만들기
`data-steps="N"`을 지정하면 → 키가 단계를 먼저 진행합니다. 단계별 화면 변화는 현재 `scatterStep(n)`처럼 별도 함수로 처리합니다.

## 9. 커스터마이징

- **브랜드 컬러 바꾸기** — `:root`의 `--accent`, `--gold`, `--paper`, `--night`만 바꾸면 전체 톤이 바뀝니다. Canvas·SVG 안의 `#ff5a36`도 함께 바꿔 주세요.
- **폰트 바꾸기** — `<link>`의 Google Fonts URL과 `--sans`, `--serif`, `--mono`를 수정합니다.
- **애니메이션 속도** — 공통 등장은 `.rise`의 `.9s`, 단어 간격은 `.word`의 `.09s`, 카운트업은 `countUp(el, to, 1700)`의 1700ms를 조정합니다.
- **데이터 교체** — 각 차트의 데이터는 `lineData`, `raceData`, `focusData`, `ringData`, `msData` 배열에 있습니다.

## 11. 브라우저 지원 · 접근성

- 최신 Chrome, Edge, Safari, Firefox에서 동작합니다. CSS 변수, `clip-path`, `aspect-ratio`, Pointer Events를 사용합니다.
- 모바일에서는 효과 노트가 하단 시트로 열리고, 스와이프로 넘길 수 있습니다.
- `prefers-reduced-motion: reduce` 환경에서는 모든 애니메이션과 전환이 즉시 완료됩니다.
- PDF 저장은 사이트를 직접 열었을 때 동작합니다. 다른 페이지 안에 iframe으로 삽입된 경우 브라우저가 인쇄를 막을 수 있습니다.
- 전체 화면과 클립보드 복사는 브라우저 정책에 따라 제한될 수 있습니다. 복사가 막히면 코드가 자동 선택되므로 `Ctrl/⌘ + C`로 복사하면 됩니다.
